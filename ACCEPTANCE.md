# Приёмка 0.4.0

Это план проверки поведения, не отчёт о пройденных тестах. Все примеры ниже синтетические. Не сохранять в Git реальные ответы ERP или файлы договоров.

После импорта: в новом чате проверить загрузку корпоративного `macro-work-assistant` **0.4.0** по журналу/прочитанному ресурсу. Название плагина и текст «использую навык» без версии/пути недостаточны. Отключённую персональную копию не включать.

| Сценарий | Ожидаемый результат |

| Ошибка авторизации MacroData/API | Остановка зависимой операции, без браузера, обхода другим коннектором или новой авторизации. |
| «Пришли файл выбранного договора» | API → файл в чат при поддержке клиента; без повторной портфельной аналитики. |
| «Измени конкретное поле» | Точное разрешённое действие, требуемые подтверждения и проверка; нет запрета «только чтение». |
| «Пять последних» | Явный критерий даты, корректная сортировка подходящих договоров; не первые ID. |
| «Сколько всего договоров?» при усечённой выборке | Нет ложного полного количества; названы ограничения. |

## Проверка скорости

Одинаковый вопрос, объект, модель и настройки; новый чат; отдельно фиксировать холодный и повторный запуск. Сравнивать одинаковый смысл («5 примеров» не равен «5 последних»). Записать длительность, число вызовов и факт загрузки навыка. Не сокращать обязательные проверки доступа/схемы ради цифры.

## Поверхности

В корпоративном пространстве СКИ проверить браузер, desktop и iOS: автоматический выбор MACRO без @, основной договор без приложений в списке, файл открывается у получателя. Отдельно проверить учётную запись коллеги с её реальными правами. Успех автора в WaiWai не заменяет эти тесты.
