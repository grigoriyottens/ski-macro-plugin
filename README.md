# СКИ — MACRO-помощник · 0.4.0

Плагин с инструкциями для работы через отдельно подключённые Macro API и MacroData. Помогает выбирать источник, отличать основные договоры от других документов и получать файлы. Не является MCP-сервером и не предоставляет доступ к ERP.

Это отдельный публичный репозиторий пакета. В нём нет договоров, файлов ERP, ключей, паролей, журналов запросов или истории другого репозитория. Публичность позволяет читать и копировать инструкции; изменять этот репозиторий могут только пользователи с выданными владельцем правами.

## Импорт в корпоративное пространство СКИ

Открой **Admin → Plugins → Add → Import marketplace**:

| Поле | Значение |
|---|---|
| Source URL | `https://github.com/grigoriyottens/ski-macro-plugin` |
| Path | Оставить пустым |
| Branch, tag, or commit | `main` |

При запросе авторизации GitHub следуй штатному процессу. Публичный репозиторий не гарантирует импорт без GitHub-подключения администратора. Доступ к другим приватным репозиториям для этого пакета не нужен.

Каталог содержит `pluginId` существующего плагина **СКИ**, чтобы перевести его с загрузки ZIP на обновления из GitHub, сохранив ID и политики. Это идентификатор, не ключ доступа. Импорт в другое рабочее пространство с этим ID не предназначен: для него нужен свой каталог.

1. Не удаляй существующий «СКИ — MACRO-помощник».
2. После импорта проверь версию **0.4.0**, статус **Enabled** и установку **Installed**.
3. Если раньше добавленный источник так и остался с нулём плагинов и ошибкой доступа, новый импорт ещё нужно проверить. Если плагин уже управляется другим GitHub-источником, остановись: простой повторный импорт с тем же ID не поддерживает перехват управления. Не удаляй каталоги наугад.
4. Начни новый чат в рабочем проекте и выполни [приёмку](ACCEPTANCE.md). Старый чат мог уже загрузить предыдущие инструкции.

Macro API и MacroData подключаются отдельно, с правами каждого сотрудника. Сам импорт не подключает их аккаунты и не создаёт проекты ChatGPT. Пакет не содержит MCP-конфигурации, которая делала бы его desktop-only. Работу в каждом клиенте проверяйте после установки; установка не гарантирует автоматический выбор навыка во всех запросах.

## Обновления

Канонический источник выпуска — этот репозиторий, ветка **main**.

1. Изменить инструкции и синхронно повысить версии в `plugins/ski-macro-assistant/.codex-plugin/plugin.json` и `skills/macro-work-assistant/SKILL.md` внутри плагина.
2. Выполнить `python3 scripts/validate_release.py` и `python3 -m unittest discover -s scripts -p 'test_*.py' -v`.
3. Проверить diff: никаких секретов, реальных ответов ERP и файлов договоров. Проверить сценарии, которых касается изменение.
4. Опубликовать проверенный коммит в `main`. CI проверяет упаковку, не поведение модели.
5. В ChatGPT открыть **Admin → Marketplaces → WAI · СКИ → Sync now**. Также предусмотрена ежедневная синхронизация.
6. Проверить новую версию и новый чат. Не требуется удалять и устанавливать плагин заново.

Откат: вернуть проверенные инструкции новым коммитом с более высоким номером версии, затем синхронизировать. Не удалять marketplace ради отката: удаление может удалить импортированные плагины.

## Изменения 0.4.0

- Спецификации, приложения, допсоглашения и прочие документы не считаются отдельными основными договорами по умолчанию.
- Тип, родительская связь и смысл названия проверяются совместно. Пустой родитель, слово «договор» и нулевая сумма не являются самостоятельным доказательством.
- Спорные карточки не добавляются ради нужного количества; ограничения выборки обозначаются.
- Поддерживается работа только с API, если MacroData отсутствует. Ошибки подключения не обходятся через браузер или другие сервисы.
- Получение конкретного файла не требует портфельной аналитики. Изменения ERP остаются разрешены по явному запросу с необходимыми подтверждениями.

Проверки структуры пакета не подтверждают импорт, скорость или поведение модели. Приёмка в пространстве СКИ выполняется после импорта.

Документация: [импорт и обновление плагинов ChatGPT](https://learn.chatgpt.com/docs/enterprise/plugin-management).
